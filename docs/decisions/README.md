# Architecture decision records

Create an ADR for every significant architecture choice using the next available `NNNN-short-title.md`. Copy `template.md`; assign a unique number before parallel work.

Start with `Proposed`. Record acceptance only with the actual decision authority and supporting evidence. Legal, customs, KYC, and financial decisions require explicit human approval. A recommendation, silence, or technical review is not that approval.

Preserve history: supersede an accepted ADR with a linked new ADR rather than rewriting its original rationale. Use `Rejected` for rejected proposals and `Superseded` for replaced decisions.

This workflow initialization does not select a new framework, backend, database, payment provider, or marketplace policy.
