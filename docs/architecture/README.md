# Architecture documents

Store scoped designs as `topic.md`. Architecture documents explain a proposed or existing design; significant architecture choices also require an ADR in `docs/decisions/`.

Include the task goal, status, current-state evidence, requirements, component and data boundaries, alternatives, security considerations, validation approach, dependencies, open questions, and links to research and ADRs. Distinguish existing behavior from proposals.

The inspected application uses Next.js App Router, React, TypeScript, and Tailwind. The project brief describes Vite; this discrepancy is recorded in `AGENTS.md` and is not authorization to migrate the framework.

Do not design unresolved legal, customs, KYC, or financial policy as if already approved. Identify the human decision needed before dependent work can proceed.
